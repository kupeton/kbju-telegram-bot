# 🥗 Telegram-бот «Мой КБЖУ»

Рабочий исходный код первой версии личного дневника питания на **TypeScript + grammY + PostgreSQL + Prisma**.

## Что умеет

- Добавлять любой продукт по КБЖУ с этикетки (пошаговый диалог).
- Отмечать магазин: «Пятёрочка», «Магнит» или другой; один продукт можно пометить несколькими магазинами.
- Искать товары в **собственном** каталоге по названию/бренду и метке магазина.
- Искать упакованный продукт **по цифровому штрихкоду** через Open Food Facts API v3 (если нет в локальной базе).
- Добавлять съеденное количество в граммах или миллилитрах и автоматически считать КБЖУ порции.
- Смотреть дневник за сегодня и сводку за последние 7 дней.
- Удалять последнюю запись и устанавливать собственную калорийную цель.
- Хранить персональные записи в PostgreSQL; чужие пользовательские карточки недоступны.
- Учитывать часовой пояс дневника.

**Что пока НЕ реализовано:** Telegram Mini App (графический интерфейс), фотоэтикетки/OCR, сканирование штрихкода камерой, поиск по *полному* ассортименту магазинов, поиск по названию во всей базе Open Food Facts. Реализован поиск по **текстовому/цифровому штрихкоду** и по **локальному каталогу**. Информация о магазине не означает подтверждённое наличие товара в продаже.

## Требования

- Node.js **22.18+** (или актуальный Node.js 24).
- npm.
- Docker Desktop (для PostgreSQL), либо установленный PostgreSQL 16+.
- Telegram и собственный токен бота, выданный [@BotFather](https://t.me/BotFather).

## Запуск за 6 шагов

Открой терминал в папке `kbju-telegram-bot`.

### 1. Создай бота в Telegram

Напиши `@BotFather` → `/newbot` → задай имя и username → скопируй токен.

**Никому не отправляй свой BOT_TOKEN и не публикуй `.env`!**

### 2. Создай файл переменных окружения

```bash
cp .env.example .env
```

На Windows без bash можешь вручную скопировать `.env.example` как `.env`.

В `.env` измени:
- `BOT_TOKEN` на токен от BotFather.
- `OFF_USER_AGENT` на строку с собственным контактом, например `MyKBJUBot/0.1 (me@mydomain.ru)` (нужно для запросов в Open Food Facts).
- `DEFAULT_TIMEZONE`, если нужно (например, `Europe/Moscow` или `America/Chicago`).

Остальные настройки оставь для первого локального запуска. Пароль в примере предназначен **только для разработки на своём компьютере**.

### 3. Подними PostgreSQL

```bash
docker compose up -d
```

Если Docker нет, создай базу PostgreSQL и укажи её данные в `DATABASE_URL`.

### 4. Установи зависимости

```bash
npm install
```

### 5. Создай таблицы и Prisma Client

```bash
npm run db:migrate
npm run db:generate
```

### 6. Запусти бота

```bash
npm run dev
```

Теперь в Telegram открой своего бота и нажми **Start** или введи `/start`.

**Важно:** с локальным запуском через long polling тебе не нужен публичный сервер или домен, но терминал с запущенным процессом должен быть открыт. Нельзя одновременно запускать два экземпляра с одним токеном через polling.

## Сценарий проверки

1. Отправь `/new`.
2. Введи последовательно: `Творог 5%`, `Простоквашино`, `Пятёрочка`, `г`, `121`, `17`, `5`, `2`.
3. Бот сохранит карточку и покажет кнопку **«➕ Съел — указать вес»**.
4. Нажми кнопку и введи `150`.
5. Бот посчитает приблизительно **181,5 ккал · Б 25,5 · Ж 7,5 · У 3** для указанных **примерных**, а не проверенных по упаковке значений.
6. Отправь `/today`, `/history`, `/search творог`, `/store пятерочка`.
7. Для отмены случайной записи используй `/undo`.

Данные КБЖУ всегда сверяй с **фактической упаковкой**. Даже товары с одинаковым названием могут отличаться по производителю, рецептуре или объёму.

## Команды

| Команда | Назначение |
|---|---|
| `/start`, `/help` | Главное меню, инструкции |
| `/new` | Пошагово добавить личный товар |
| `/search творог` | Найти товар в локальном каталоге |
| `/store магнит` | Товары с меткой «Магнит» |
| `/barcode 3017620422003` | Поиск по штрихкоду через Open Food Facts |
| `/today` | КБЖУ за текущий день |
| `/history` | Итоги за последние 7 дней |
| `/undo` | Удалить последнюю запись |
| `/goal 2200` | Установить свою дневную цель в ккал |
| `/timezone Europe/Moscow` | Изменить часовой пояс дневника |
| `/cancel` | Отменить активный диалог |

Текстовое название можно отправить просто сообщением. Штрихкод из 8–14 цифр тоже можно отправить без команды. Для добавления порции используй inline-кнопку после результата поиска.

## Как устроено

```text
src/
  bot.ts          Telegram-команды, диалоги, запись в дневник
  db.ts           Prisma + PostgreSQL
  nutrition.ts    Чистые функции подсчёта КБЖУ и даты
  off.ts          Запрос Open Food Facts API v3 по штрихкоду
prisma/
  schema.prisma   Таблицы пользователей, продуктов и приёмов пищи
tests/
  nutrition.test.ts
  off.test.ts
```

`FoodEntry` хранит **снимок КБЖУ** на момент добавления, чтобы история не изменялась при редактировании товара. Продукты, добавленные вручную, принадлежат конкретному пользователю. Из Open Food Facts импортируются общие карточки.

Для проверки автоматических тестов:

```bash
npm test
npm run check
```

## Источники и ограничения

Данные по штрихкоду: [Open Food Facts](https://world.openfoodfacts.org/) — открытая база, не являющаяся официальным каталогом Пятёрочки или Магнита. Запрашиваем продукт только по API v3 и **только при наличии всех четырёх значений** (калории, белки, жиры и углеводы); отсутствующие значения не заменяются нулём. Автоматически полученные сведения могут быть неполными/ошибочными. При использовании/распространении данных учитывай лицензию **Open Database License (ODbL)**, требования атрибуции и применимые условия API: [документация](https://openfoodfacts.github.io/documentation/docs/Product-Opener/api/).

Разделение на магазины пока основано на **метках, вводимых самим пользователем**: никакой неподтверждённой информации об ассортименте и наличии в конкретных торговых точках бот не выдаёт.

## Запуск локально и публикация на GitHub

Скопируй пример настроек в `.env` и заполни его своими значениями. Получи новый токен у [@BotFather](https://t.me/BotFather); не добавляй `.env` в GitHub.

```powershell
Copy-Item .env.example .env
npm install
docker compose up -d
npm run db:migrate
npm run db:generate
npm run dev
```

Для проверки перед публикацией запусти `npm test` и `npm run check`. Создай на GitHub пустой репозиторий без README, затем из папки проекта добавь только необходимые исходники и проверь список:

```powershell
git init
git branch -M main
git add .gitignore .env.example LICENSE README.md README_DETAILED.md docker-compose.yml package.json package-lock.json prisma.config.ts tsconfig.json prisma src tests
git status
```

Убедись, что в списке нет `.env`, `node_modules`, `generated/prisma` и временных файлов. После проверки добавь адрес пустого репозитория и отправь коммит:

```powershell
git commit -m "Initial commit: KBJU Telegram Bot v1.0"
git remote add origin https://github.com/USERNAME/kbju-telegram-bot.git
git push -u origin main
```
